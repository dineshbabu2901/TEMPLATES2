IAIS INDIA — 25 LIVE WEBSITE THEMES
===================================

START HERE
1. Open index.html in any modern browser.
2. Click any of the 25 theme cards.
3. Each theme is a full long-scroll homepage.
4. Use the bottom-right arrows on desktop to move between themes.

FILES
- index.html: visual theme gallery
- themes/theme-01.html ... theme-25.html: complete homepage themes
- assets/styles.css: shared responsive design system + 25 palettes
- assets/script.js: mobile menu, reveal animations, animated counters
- assets/iais-india-logo.png: optimized transparent copy of the supplied logo
- assets/previews/: preview images for the theme gallery
- credits.html: online image credits / licensing reminder

TECHNOLOGY
Vanilla HTML5, CSS3 and JavaScript. No framework or build step required.
The theme pages use remote Unsplash images, so an internet connection is needed for photography.
